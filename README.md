# Product Funnel and Cohort Analysis

Небольшой учебный проект по продуктовой аналитике на данных интернет-магазина.

Я сделал этот проект, чтобы показать базовые навыки, которые нужны начинающему продуктовому аналитику: работа с событиями пользователей, SQL-запросы, расчёт воронки, конверсий и когортного удержания.

## Что анализируется

В проекте рассматривается простая e-commerce воронка:

```text
view → addtocart → transaction
```

То есть пользователь сначала смотрит товар, затем может добавить его в корзину, а после этого совершить покупку.

В notebook я смотрю:

- сколько пользователей доходит до каждого шага воронки;
- на каком этапе теряется больше всего пользователей;
- какая конверсия между шагами;
- как меняется активность пользователей по когортам;
- отличаются ли конверсии у разных пользовательских сегментов;
- какие продуктовые гипотезы можно предложить по результатам анализа.

## Данные

Для проекта используется открытый датасет Retailrocket Ecommerce Dataset с событиями пользователей интернет-магазина.

В данных есть основные поля:

- `visitorid` — идентификатор пользователя;
- `event` — тип события: `view`, `addtocart` или `transaction`;
- `itemid` — идентификатор товара;
- `timestamp` — время события;
- `transactionid` — идентификатор покупки, если событие связано с транзакцией.

Сами данные в репозиторий не добавлены, потому что исходный файл достаточно большой. Его нужно скачать отдельно с Kaggle.

Команда для загрузки:

```bash
pip install kaggle
kaggle datasets download -d retailrocket/ecommerce-dataset -p data/raw --unzip
```

После загрузки файл должен лежать здесь:

```text
data/raw/events.csv
```

## Как запустить проект

Сначала нужно создать виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

Затем установить зависимости:

```bash
pip install -r requirements.txt
```

После этого нужно скачать датасет и положить файл `events.csv` в папку `data/raw/`.

Запуск notebook:

```bash
jupyter notebook notebooks/product_funnel_and_cohort_analysis.ipynb
```

## Что есть в notebook

В notebook последовательно выполнены следующие шаги:

1. загрузка и первичная проверка данных;
2. преобразование времени событий в нормальный формат;
3. общий обзор событий и пользователей;
4. SQL-запросы через DuckDB;
5. расчёт пользовательской воронки;
6. расчёт строгой последовательной воронки;
7. когортный анализ удержания;
8. сравнение конверсий между пользовательскими сегментами;
9. формулировка продуктовых выводов.

Отдельно отмечено, что сравнение сегментов не является полноценным A/B-тестом, потому что в датасете нет случайного разделения пользователей на контрольную и тестовую группы. Здесь оно используется как пример логики, похожей на анализ продуктового эксперимента.

## Основные вопросы проекта

В проекте я отвечаю на несколько практических вопросов:

- какая часть пользователей добавляет товар в корзину после просмотра;
- какая часть пользователей доходит до покупки;
- где находится основной провал воронки;
- возвращаются ли пользователи в следующие месяцы;
- какие изменения в продукте можно было бы проверить через A/B-тест.

## Возможные продуктовые гипотезы

По результатам анализа можно сформулировать несколько гипотез:

- улучшить карточку товара, если много пользователей смотрят товар, но не добавляют его в корзину;
- сделать кнопку добавления в корзину более заметной;
- раньше показывать информацию о доставке и цене;
- упростить путь от корзины до покупки;
- использовать напоминания или рекомендации для возвращения пользователей.

**Product funnel and cohort analysis**
